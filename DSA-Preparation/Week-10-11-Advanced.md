## Key Patterns to Remember

### Backtracking Template
```python
def backtrack(path, choices):
    if is_solution(path):
        result.append(path[:])
        return
    
    for choice in choices:
        if is_valid(choice):
            path.append(choice)         # Make choice
            backtrack(path, new_choices) # Recurse
            path.pop()                   # Undo choice (backtrack)

# Usage
result = []
backtrack([], initial_choices)
return result
```

### Greedy Proof Technique
```
1. Greedy Choice Property: A locally optimal choice leads to globally optimal
2. Optimal Substructure: Optimal solution contains optimal solutions to subproblems

Common Greedy Strategies:
- Sort by end time (interval scheduling)
- Sort by ratio (fractional knapsack)
- Always pick maximum/minimum available
```

### Interval Problems Approach
```python
# Merge Intervals Pattern
def merge_intervals(intervals):
    intervals.sort(key=lambda x: x[0])
    merged = []
    
    for interval in intervals:
        if not merged or merged[-1][1] < interval[0]:
            merged.append(interval)
        else:
            merged[-1][1] = max(merged[-1][1], interval[1])
    
    return merged
```

### Bit Manipulation Tricks
```python
# Common Operations
n & (n - 1)      # Remove lowest set bit
n & (-n)         # Get lowest set bit
n | (n + 1)      # Set lowest unset bit
n ^ n = 0        # XOR same number = 0
a ^ b ^ a = b    # XOR cancels out

# Check if bit is set
(n >> i) & 1

# Set bit at position i
n | (1 << i)

# Clear bit at position i
n & ~(1 << i)

# Toggle bit at position i
n ^ (1 << i)
```

### Trie Implementation
```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end
    
    def starts_with(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```

## When to Use What?

| Problem Type | Technique |
|--------------|-----------|
| Generate all subsets/permutations | Backtracking |
| Find path in grid | Backtracking + DFS |
| Optimize without looking ahead | Greedy |
| Schedule with least conflicts | Greedy (sort by end time) |
| Merge overlapping | Sort + Linear scan |
| Find missing/duplicate | XOR |
| Count set bits | n & (n-1) trick |
| Prefix search | Trie |
| Autocomplete | Trie |
