## Key Patterns to Remember

### Linked List Patterns
```
1. Fast & Slow Pointers (Floyd's Algorithm)
   - Cycle detection: fast moves 2x, slow moves 1x
   - Find middle: when fast reaches end, slow is at middle
   
2. Dummy Head Technique
   - Create dummy node to handle edge cases
   - Return dummy.next as result
   
3. In-place Reversal
   - prev = null, curr = head
   - while(curr): next = curr.next, curr.next = prev, prev = curr, curr = next
```

### Tree DFS Patterns
```
1. Preorder:  root -> left -> right (good for copying trees)
2. Inorder:   left -> root -> right (BST gives sorted order)
3. Postorder: left -> right -> root (good for deletion)

Key insight: Most tree problems can be solved with:
- What info do I need from subtrees?
- What do I do with that info at current node?
```

### Tree BFS Pattern
```python
def bfs(root):
    if not root: return []
    queue = deque([root])
    result = []
    while queue:
        level_size = len(queue)
        level = []
        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        result.append(level)
    return result
```

### BST Property
```
- Left subtree: all values < root
- Right subtree: all values > root
- Inorder traversal gives sorted sequence
```
