## Key Patterns to Remember

### Arrays & Hashing
- Use **HashMap** for O(1) lookup
- **Prefix Sum** for range queries
- **Cyclic Sort** for numbers in range [1, n]

### Two Pointers
- Start from both ends for sorted arrays
- Slow/Fast for same direction problems
- Sort first if needed

### Sliding Window
- Fixed size: simple expand/shrink
- Variable size: expand until invalid, then shrink
- Use HashMap for character frequency

### Stack
- Use for **matching pairs** (parentheses)
- **Monotonic Stack** for next greater/smaller
- Think "what do I need to remember?"

### Binary Search
- Classic: find target
- **Binary Search on Answer**: minimize/maximize answer
- Always handle edge cases carefully
