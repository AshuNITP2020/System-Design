## Mock Interview Schedule

### Daily Mock Template (45-60 min each)

```
Day 1 AM: Easy + Medium (Google style)
Day 1 PM: Medium + Medium (Amazon style)

Day 2 AM: Medium + Hard (Meta style)
Day 2 PM: Design + Coding (System Design prep)

Day 3 AM: Hard + Medium (Practice weakness)
Day 3 PM: Timed contest (2 hours, 4 problems)

Day 4-5: Company-specific problem marathon
Day 6-7: Light revision + Rest
```

### Mock Interview Tips

```
1. TIME MANAGEMENT
   - 5 min: Understand problem, ask clarifying questions
   - 5 min: Discuss approach, get interviewer buy-in
   - 25 min: Code the solution
   - 10 min: Test, debug, optimize
   
2. COMMUNICATION
   - Think out loud
   - Explain trade-offs
   - Ask before assuming
   
3. EDGE CASES TO ALWAYS CHECK
   - Empty input
   - Single element
   - All same elements
   - Sorted / Reverse sorted
   - Negative numbers
   - Integer overflow
   
4. IF STUCK
   - Start with brute force
   - Ask for hints (it's okay!)
   - Draw examples
   - Think about similar problems
```

## Quick Pattern Recap

### When to Use What

| See This | Think This |
|----------|------------|
| "k largest/smallest" | Heap (opposite heap type) |
| "top k frequent" | HashMap + Heap |
| "shortest path unweighted" | BFS |
| "shortest path weighted" | Dijkstra |
| "connected components" | Union Find / DFS |
| "prerequisites/order" | Topological Sort |
| "substring with condition" | Sliding Window |
| "find in sorted" | Binary Search |
| "all combinations" | Backtracking |
| "optimal decision" | DP |
| "next greater" | Monotonic Stack |
| "prefix search" | Trie |
