## How to Use This Plan

### Daily Routine
```
1. Pick problems from current week's list
2. Follow the UMPIRE method for each problem
3. Mark completion in Problem-Tracker.md
4. Review solutions and note patterns
5. Re-solve marked problems after 3 days
```

### Problem-Solving Framework (UMPIRE)
- **U**nderstand: Read problem twice, identify constraints
- **M**atch: Identify pattern from cheat sheet
- **P**lan: Write approach before coding
- **I**mplement: Clean, readable code
- **R**eview: Dry run with examples
- **E**valuate: Time/Space complexity
