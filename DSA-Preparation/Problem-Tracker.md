## Common Mistakes Log

### Edge Cases I Keep Missing

| Problem Type | Edge Case | Solution/Remember |
|--------------|-----------|-------------------|
| Array | Empty array | Check length first |
| String | Empty string | Handle "" case |
| Tree | Null root | Return early |
| LL | Single node | Check head.next |
| Graph | Disconnected | Handle all components |
| DP | Base case | Initialize properly |

### Bugs I Keep Making

| Bug Type | Example | Fix |
|----------|---------|-----|
| Off-by-one | `i < n` vs `i <= n` | Draw array indices |
| Integer overflow | Large numbers | Use long/BigInteger |
| Modifying during iteration | ConcurrentModification | Use new list |
| Not returning | Missing return | Check all paths |
